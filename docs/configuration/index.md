# Configuration

Compilation parameters and description of library classes

Classes are arranged in a hierarchy: Lcd2004 serves as the base, Lcd2004xs adds virtual slots, and Lcd2004gfx and Lcd2004ru are built on top of Lcd2004xs

## Section pages

- [Lcd2004](Lcd2004.md): base class, works directly with the display
- [Lcd2004xs](Lcd2004xs.md): virtual slots for your own characters
- [Lcd2004gfx](Lcd2004gfx.md): graphics mode via GyverGFX
- [Lcd2004ru](Lcd2004ru.md): Cyrillic and UTF-8 support
