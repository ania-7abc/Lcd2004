# Lcd2004 configuration

This page describes the build flags that change the behavour of the `Lcd2004` class and what they mean for your sketch

## Build flags

### `LCD_NO_I2C`

Default: not defined

Disables all I2C support in `Lcd2004`

When defined:

- `<Wire.h>` is not included
- `i2c_mode_`, `i2c_data_`, and `i2c_addr_` are removed from the class
- the I2C constructor `Lcd2004(addr, cols, rows)` is not available
- `setPin` becomes a static function that only calls `digitalWrite`
- `pulseEnable` becomes a `const` member and only uses direct pins
- `setBacklight` becomes `const` and only controls the backlight pin

User impact:

- you cannot use an I2C backpack with this build
- you must connect the LCD using parallel pins
- the I2C constructor will not compile
- backlight control is limited to the direct backlight pin
- flash and RAM usage are slightly lower

### `LCD_LOW_MEM`

Default: not defined

Reduces RAM usage by removing optional features from `Lcd2004`

When defined:

- `BLA_` backlight pin member is removed
- `display_`, `cursor_`, and `cursor_blink_` state variables are removed
- `setOn` and `setCursor` are not available
- `saveCustomChar` is not available
- `displayControlCmd` is not available
- `preWrite` is not available
- `write` does not handle `\n`, `\r`, or `\b`
- automatic line wrap after the last column is disabled
- `setBacklight` is not available

User impact:

- no backlight control from the library
- no display on/off control
- no cursor or blink control
- no custom character support
- newline, carriage return, and backspace are written as normal bytes
- text does not automatically wrap to the next line
- RAM usage is lower

Note: `Lcd2004xs` and classes derived from it cannot be used together with `LCD_LOW_MEM`. The compiler will stop with an
error

### `LCD_USE_BUFFER`

Default: not defined

Adds a software buffer for the display contents

When defined:

- `position_` and `buffer_[0x68]` are added to the class
- `clear` fills the buffer with spaces instead of sending the clear command
- `write` stores bytes in the buffer instead of sending them to the LCD
- `flush` sends the buffer contents to the LCD
- `init` calls `clear` and then `flush`
- `setPosition` updates `position_`

User impact:

- you must call `flush()` to make changes visible on the LCD
- `clear()` only clears the internal buffer
- you can compose a full screen in memory and update the LCD in one pass
- the buffer uses 104 bytes of RAM

## Font constants

`LCD_FONT_5X8` and `LCD_FONT_5X10` are constants for the `init` method

- `LCD_FONT_5X8` selects the 5x8 font
- `LCD_FONT_5X10` selects the 5x10 font

User impact:

- call `init(LCD_FONT_5X10)` if your LCD supports the taller font
- the default is `LCD_FONT_5X8`

## Internal command defines

The `LCD_CMD_*` defines are internal command values for the HD44780 controller. They are not meant to be changed by the
user

## Constructors

Available constructors depend on the build flags

Parallel 8-bit mode:

```cpp
Lcd2004(RS, E, D0, D1, D2, D3, D4, D5, D6, D7, cols, rows, BLA = -1);
```

Parallel 4-bit mode:

```cpp
Lcd2004(RS, E, D4, D5, D6, D7, cols, rows, BLA = -1);
```

I2C mode, only when `LCD_NO_I2C` is not defined:

```cpp
Lcd2004(addr, cols, rows);
```

User impact:

- with `LCD_NO_I2C` defined, the I2C constructor is unavailable
- in 4-bit mode, only four data pins are used
- the `BLA` parameter controls the backlight pin when `LCD_LOW_MEM` is not defined

## Methods affected by flags

| Method           | `LCD_LOW_MEM`  | `LCD_USE_BUFFER`          | `LCD_NO_I2C`    |
|------------------|----------------|---------------------------|-----------------|
| `init`           | available      | calls `clear` and `flush` | available       |
| `clear`          | available      | clears buffer             | available       |
| `returnHome`     | available      | resets buffer position    | available       |
| `setOn`          | removed        | available                 | available       |
| `setCursor`      | removed        | available                 | available       |
| `setPosition`    | available      | updates buffer position   | available       |
| `saveCustomChar` | removed        | available                 | available       |
| `write`          | raw bytes only | writes to buffer          | available       |
| `flush`          | not present    | available                 | available       |
| `setBacklight`   | removed        | available                 | direct pin only |

## Example configurations

Minimal RAM for parallel LCD:

```cpp
#define LCD_LOW_MEM
#define LCD_NO_I2C
#include <Lcd2004.h>
```

I2C LCD with default features:

```cpp
#include <Lcd2004.h>
Lcd2004 lcd(0x27, 20, 4);
```

Buffered LCD for flicker-free updates:

```cpp
#define LCD_USE_BUFFER
#include <Lcd2004.h>
Lcd2004 lcd(0x27, 16, 2);
// after drawing:
lcd.flush();
```
